# 示例燃气有限公司考勤与休假管理办法

## 一、工作时间
公司实行标准工时制：上午8:30至12:00，下午14:00至18:00，每周工作五天。

## 二、迟到与旷工
迟到超过30分钟按旷工半天处理；月累计迟到5次以上的，扣发当月全勤奖。

## 三、请假
1. 事假：需提前1个工作日提交申请，由部门负责人审批。
2. 病假：需提供二级以上医院证明。
3. 婚假：员工本人结婚，婚假3天。
4. 产假：女职工产假98天。
5. 年休假：工作满1年不满10年的，年休假5天；满10年不满20年的，10天。

## 四、加班
加班须提前申请，经批准后可按1:1安排调休，或按规定支付加班工资。
